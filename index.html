How to use this tool ▾
  1. Enter a word or phrase that is meaningful to you — avoid names, birthdays and common words. Consider using long base words with 8+ characters
  2. Click Generate — the system will check your input and transform it into a strong password.
  3. If a warning appears — your input contains personal information. Try a different word.
  4. Copy your password using the copy button and use it immediately.
  5. Optional: Save it temporarily by checking the save box and creating a passphrase. You will need this passphrase to retrieve it — it cannot be recovered if forgotten.
